# 종합부동산세 정부부과 원칙·신고선택 예외

종합부동산세는 원칙적으로 관할 세무서장이 납부할 세액을 결정·고지하는 정부부과 방식이나(납부기간 12.1~12.15), 납세의무자가 신고를 선택하면 신고납세 방식으로 과세표준과 세액을 확정할 수 있다(종합부동산세법 제16조 제3항).

## 근거와 적용 범위

- 법적 근거: 종합부동산세법 제16조(부과·징수 등) 제3항
- 공식 출처: [원문 확인](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2351&cntntsId=7733)
- 자료 기준일: 2026-06-15
- 적용 기준일: 2026-06-15
- 다음 검토일: 2027-03-31
- 적용 범위·주의: 신고선택 시에만 신고납세로 전환되며 기본은 정부 결정·고지. 종부세법 제16조 제3항 항번호는 개정본 확인 권장. 국세청 안내(2차) 교차확인.
